= Quickstart
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+
* just (command runner)
* Your language toolchain (see Justfile for details)

== Checkout

[source,bash]
----
git clone https://github.com/metadatastician/enaction-engine.git
cd enaction-engine
cargo test --workspace
----
