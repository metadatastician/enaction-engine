== Open merge blockers

=== Literal action-pin scanners versus the enforced lock model

CodeQL, Codacy and Sonar all flag the same two
`dtolnay/rust-toolchain@v1` lines. Enaction uses the estate's Actions lockfile
model: repository settings require SHA pinning, runner logs resolve locked
versions, and `gh actions-lock --verify` reports zero findings. The external
analysers inspect literal YAML and do not consume that execution model.

Standards issue 674 forbids the tempting workarounds: no inline pins, alert
dismissals or threshold reductions. Required CodeQL and Sonar contexts remain
in the ruleset. Resolution therefore needs upstream scanner support or an
explicit future standards decision; pull request 53 remains blocked meanwhile.

current purity gate. It does not implement the sixteen-connector unified API
and must not claim that surface without a real protocol-facing consumer.

Idris2 ABI and Zig FFI:: Idris2 is normative for ABI types/layouts; generated
declarations are deterministic wire artifacts; Zig implements the boundary;
host languages do not independently redefine it.

Rust and Creusot:: One production predicate now has a Creusot contract and a
fail-closed, positive-controlled local gate. No proof claim extends to the
planner, kernels or adapter; GitHub Actions provisioning remains a gap.

Idris2 pointer policy:: The production ABI now proves that a valid non-empty
buffer requires data and a valid null data pointer denotes an empty buffer.
Zig exercises the corresponding rejection paths, but the Idris-to-Zig
refinement remains a recorded gap rather than a proof claim.
