= Test and Verification Inventory
:toc:

*CRG status:* no formal assessment; this page assigns no grade.

This inventory records the current test and verification surfaces. A recipe or
test file existing is not evidence that it passed; use the linked CI run or
local command output for results.

== Implemented checks

|===
| Surface | Entry point | Scope and boundary

| Default Rust members
| `cargo test --locked --all-targets` or `just test`
| Tests the workspace's default Rust members. The Zig-linked native adapter is
  deliberately excluded from this default set.

| Accelerator conformance
| `bash tests/e2e.sh` or `just e2e`
| Checks the committed v1 corpus checksums, the Rust scalar reference, and the
  Zig-native adapter against the same fixtures. Missing Cargo, Zig, or a failed
  leg is a failure, not a skip.

| Pure-Zig accelerator tests
| `cd src/interface/ffi && zig build test`
| Runs the tests colocated with the production accelerator implementation.
  There is no separate generic lifecycle module or placeholder integration test.

| ABI generation and provenance
| `scripts/generate-accelerator-abi.sh --check` and
  `sha256sum -c src/interface/generated/abi/SOURCE.sha256`
| Checks generated C-compatible, Zig, Rust, and Julia declarations against the
  Idris2 authority and verifies the recorded source digests.

| Formal verification
| `just proof-check-all`
| Checks the configured Idris2, Lean, Agda, Coq, and Creusot proof surfaces.
  Missing required toolchains fail the gate; they are not reported as proof.

| Workflow configuration
| `tests/workflows/`
| Shell regression tests for workflow pins, required workflow inventory, and
  lockfile synchronization. `scripts/check-lock-sync.sh` checks both directions
  and transitive dependency closure.

| Repository status and source hygiene
| `tests/aspect_tests.sh`, `scripts/check-source-spdx.sh`,
  `tests/readiness_status_test.sh`, `tests/contractile_safety_test.sh`, and the
  README badge tests
| Checks source headers, banned proof escapes, the reviewed Zig pointer-cast
  policy, the removed generic scaffold, generated-recipe safety, and honest
  public status claims.
|===

== Boundaries and unfinished test surfaces

* There is no playable game or executable engine host, so application lifecycle
  and game-level integration tests do not exist yet.
* No runnable benchmark suite is present. `just bench` fails explicitly rather
  than printing a placeholder success.
* `tests/fuzz/README.adoc` documents future fuzzing work; it is not a fuzz
  harness or evidence that fuzz tests have run.
* `scripts/validate-template.sh` checks repository and ABI structure. If Zig or
  Idris2 is unavailable, it reports a warning and does not claim that compiler
  check passed. A full compiler-backed gate is provided by CI and the relevant
  `just` recipes.
* No completed CRG assessment, aggregate grade, or readiness badge is claimed.
  See link:READINESS.adoc[readiness status].
