= Enaction Engine Quick Start

Enaction Engine currently ships the Rust library crate `enaction-time`. It is an
early deterministic timing and render-interpolation substrate, not a runnable
editor or complete engine application.

== Prerequisites

Install a Rust 2024-edition toolchain and `cargo`. The `just` task runner exposes
the repository's common commands.

== Get and test the source

[source,bash]
----
git clone https://github.com/metadatastician/enaction-engine.git
cd enaction-engine
cargo test --workspace
----

== Use the current crate

Add `enaction-time` as a path dependency while the crate is unreleased:

[source,toml]
----
[dependencies]
enaction-time = { path = "../enaction-engine/crates/enaction-time" }
----

Import it as `enaction_time`:

[source,rust]
----
use enaction_time::{DoubleBuffer, FixedStep};
----

Simulation code must consume only the whole steps returned by `FixedStep`.
Values sampled from `DoubleBuffer` are presentation-only and must not re-enter
simulation state. Read `README.adoc` and `EXPLAINME.adoc` before integrating.

== Current limits

There is no renderer, editor, ECS, audio, input, assets, physics, networking, or
complete cognitive, affective, or conative subsystem in this repository today.
