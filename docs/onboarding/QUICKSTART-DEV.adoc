= Enaction Engine Developer Quick Start

== Orientation

Read `AGENTS.md`, `ARCHITECTURE.md`, `EXPLAINME.adoc`, and the accepted records
in `docs/decisions/`. The implemented workspace contains one crate:
`crates/enaction-time`.

The non-negotiable boundary is whole-step simulation plus render-only
interpolation. Preserve the measured floating-point behaviour and the
`commit`-then-`snap` discontinuity rule.

== Checkout and verify

[source,bash]
----
git clone https://github.com/metadatastician/enaction-engine.git
cd enaction-engine
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
just verify
----

== Repository shape

[source,text]
----
crates/enaction-time/        implemented Rust crate and tests
docs/architecture/           target architecture and UMS boundary
docs/decisions/              accepted ADRs
docs/status/ROADMAP.adoc     evidence-gated direction
.machine_readable/           RSR declarations and contractiles
----

Do not add placeholder subsystem crates. A new component requires a real
proving-ground need, implementation, tests, dependency boundaries, provenance,
and an honest account of what remains unproved.
