= LLM Warmup — enaction-engine (Developer)

== What is Enaction Engine?

A deterministic, type-safe game engine for worlds shaped through perception,
affect, intention, action and consequence. The current Rust implementation is
only the `enaction-time` timing and interpolation substrate.

== Key Commands

* `just setup` — set up development environment
* `cargo fmt --all -- --check` — check Rust formatting
* `just test` — run workspace tests
* `cargo clippy --workspace --all-targets -- -D warnings` — lint Rust
* `just verify` — run RSR verification
