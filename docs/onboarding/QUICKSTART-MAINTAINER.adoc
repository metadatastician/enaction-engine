= Enaction Engine Maintainer Quick Start

== Release posture

The current distributable unit is the `enaction-time` Rust crate. Do not present
the repository as a complete engine release, executable service, or editor.

== Maintainer verification

[source,bash]
----
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
just test
just verify
bash scripts/check-root-shape.sh
----

Review `EXPLAINME.adoc` for claim-to-evidence boundaries and
`docs/status/EXTERNAL-ACTIONS.adoc` before enabling external badges. Provider
projects and badges must use the canonical identity and must resolve before
publication.

== Release checks

* Confirm Cargo metadata names `enaction-time`, imported as `enaction_time`.
* Confirm repository and package URLs use
  `https://github.com/metadatastician/enaction-engine`.
* Inspect every occurrence of “affective”; it is permitted only for an actual
  affective concept or subsystem.
* Preserve AGPL-3.0-or-later for code and CC-BY-SA-4.0 for prose.
* Record whether code has run in IDApTIK, another game, or only repository tests.
* Reject speculative empty subsystems and unverified complete-engine claims.
