    // SPDX-License-Identifier: AGPL-3.0-or-later

Prose documentation is CC-BY-SA-4.0. The full text of both licences lives in
LICENSES/, and the root LICENSE is the complete AGPL-3.0 text — a stub there
makes GitHub report the repository as "NOASSERTION" rather than AGPL-3.0.

Note the network clause: AGPL §13 requires that users interacting with a
modified version *over a network* be offered its source. That is deliberate for
an engine, and is the practical difference from the MPL the template ships.
