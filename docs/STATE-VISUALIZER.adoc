== Intended integration order

. Establish one small, headless host that advances a deterministic world by
  whole `enaction-time` steps and records replayable inputs.
. Integrate typed trace events at an explicit host boundary; prove that trace
  observation cannot silently become simulation input.
. Add a stable, versioned content-package contract. Keep engine/runtime and
  UMS editor/application independently usable; exchange validated data through
  documented contracts only.
. Add one real game consumer and end-to-end determinism/replay tests before
  generalising world, entity/component, physics, or presentation abstractions.
. Add rendering, input, audio, networking, persistence, and tools only when a
  working consumer establishes the contract and the associated tests.

This sequence is a plan, not a claim that those integrations exist. See
link:architecture/TOPOLOGY.adoc[architecture topology] and
link:status/ROADMAP.adoc[roadmap].
