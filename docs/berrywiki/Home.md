# Enaction Engine

Rust control plane, UMS contracts, and pure-Zig accelerator ABI.

The engine owns orchestration and the stable pure-Zig accelerator implementation; Rust links the static form and Julia loads the shared form.

This BerryWiki notebook is the human-facing index; the repository's machine-readable state file is authoritative for automation.
