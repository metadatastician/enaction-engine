== Companion documents and repo metadata (cross-check)

* `README.adoc` calls Enaction Engine an experimental set of deterministic,
  type-safe game-engine library foundations that is "not yet a complete game
  engine or runnable host". The GitHub repository description says the same:
  component libraries only. The runs below agree. They test separate
  libraries; nothing integrates them into a running host.
* The README's central invariant is that the simulation advances only in
  whole, equal steps, and that render interpolation never feeds simulation
  state. The `enaction-time` tests (`step.rs`, `blend.rs`,
  `idaptik_parity.rs`) exercise that invariant, and they pass.
* This file replaces an earlier `AFFIRMATION.adoc` that was the unfilled
  estate template (placeholder heading and anchor fields). It made no claims,
  so it is replaced in place rather than archived. Git history keeps it.

== The honest state (one breath)

At the anchor, the golden path `just test && just verify` passes: 123 Rust
tests across four crates, clippy with `-D warnings`, a formatting check, the
aspect, readiness and contractile-safety gates, and an e2e suite showing
byte-identical Rust and Zig output against a locked corpus. The Agda and Coq
proofs check. Not everything holds. `just ci` fails at its Idris2 ABI step
(`Abi/Accelerator.idr:230`). The Lean gate passes only because its single file
is quarantined. `actions.lock` has drifted from two workflows, which the
repository's own checker and CI both report.

  ("has never compiled"; a type mismatch in `Nat.zero_le max` at line 44).
  No Lean proof is checked.
* *The Idris2 verification gate passes one file.* `just proof-check-idris2`
  exits 0. Only `ABI/Foreign.idr` actually checks. Five files are quarantined

  `ABI/Compliance.idr` (for example `Undefined name LTE`).
* *`just quality` was not run as one command.* Each of its components was
  run separately and passed. The combined recipe was not invoked.
* *Three manifest warnings.* Cargo warns that the workspace dependencies
  `enaction-time` (`Cargo.toml:40`), `enaction-contracts` (`:42`) and
  `enaction-accelerator-native` (`:44`) are declared but unused.
  Clippy's `-D warnings` does not cover manifest warnings, so the lint still
  passes.
* *`just verify` checks for retired-format files.* It requires

== Reproduce it yourself

From a clone checked out at the anchor commit:

[source,bash]
----
git checkout 0e7f3e78fbd95e306da34373a6b8cb5f9e64f1ff
just test && just verify                  # golden path: 123 tests pass
just fmt-check lint aspect readiness contractile-safety e2e
just proof-check-idris2-abi               # rc=1 at Abi/Accelerator.idr:230
just proof-check-idris2 proof-check-agda proof-check-coq proof-check-lean4
just proof-scan-dangerous
bash scripts/check-lock-sync.sh           # rc=1: codeql.yml, oikosbot.yml
for t in tests/workflows/*.sh; do bash "$t"; done   # foundation CI: 18/20
----

If `mise` shims are on your `PATH` and you have not trusted this repository's
`mise.toml`, remove them from `PATH` first, or the `cargo` shim exits 1.

Agda needs agda-stdlib. Point `AGDA_DIR` at a directory whose `libraries` file
names the stdlib's `.agda-lib` and whose `defaults` file says
`standard-library`.
