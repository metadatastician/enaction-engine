= Idris2 ABI authority

`Accelerator.idr` is the source of truth for the accelerator contract's fixed
numeric discriminants and native layouts. It proves the admitted request,
buffer, capability and evidence structures against `Layout.idr`'s
`CABICompliant` model.

`Generate.idr` deterministically renders the C-compatible, Zig, Rust and Julia
declarations. Installed Idris2 0.7.0 has no `c-header` backend; do not restore
the inherited but nonexistent `idris2 --cg c-header` workflow.

[source,sh]
----
idris2 --typecheck abi.ipkg
scripts/generate-accelerator-abi.sh
scripts/generate-accelerator-abi.sh --check
----
